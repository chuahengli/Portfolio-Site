## What's on the site

**Engineering projects** - embedded firmware (ESP32-S3, Arduino), custom KiCad PCB design, electronics prototyping, electromagnetics and antenna work, engineering analysis and machine learning. Each project links to real, first-party evidence: schematics, PCB layouts, fab outputs, source code, demo videos and reports.

**Python, data & equity research** - including my personal stock-portfolio tracker and a structured, methodical approach to quantitative research.

**Recognition** - awarded certificates, including 1st Prize at SEMI Tech Zoomers 2026, the DTI Sustainability Practice Prize, and a One Raft One Nation (APEX) certificate of participation.

A few things I'm proud of:

- **Autonomous material-flow robot ("Falali")** - a low-profile robot that moves non-standard ~70 kg cage trolleys with no retrofits. Includes a custom KiCad PCB (schematic - layout - fab) and ESP32-S3 firmware driving a professional five-state arm state machine.
- **"Alleviate" sit-to-stand bed assist** - the mechanical design backed by a 1,000,000-run Monte-Carlo torque model, engineered to a 95th-percentile torque with a safety factor of 2.
- **Flexible 2.45 GHz antenna (CST)** - full-wave electromagnetic simulation, including a stretchable liquid-metal "Kintenna" that cuts resonant drift by ~25% vs a flat control at 20% strain.
- **Stock portfolio tracker** - a Python pipeline ingesting live brokerage data into SQLite, presented through a Streamlit/Plotly dashboard (preview shown with illustrative sample data).
